Model Comparison

Logistic Regression, Decision Tree and Random Forest were trained and evaluated on the same stratified held-out test set.

Why Logistic Regression?

Random Forest achieved higher accuracy, but Logistic Regression achieved 64.4% recall and 76.0% ROC-AUC. For maintenance screening, reducing missed elevated-risk cases is an important business consideration.

Features

Downtime, cycle time, cycle-time variation, alarms, maintenance events, days since preventive maintenance, OEE and JPH attainment.

Tools

Python, Pandas, NumPy, scikit-learn, Logistic Regression, Decision Tree, Random Forest, Git and GitHub.

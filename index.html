Artifact 1 Working Prototype

FactoryAssist AI Reaction-Plan Assistant

Manufacturing operators and maintenance teams often need clear, consistent guidance when equipment problems occur. FactoryAssist AI explores how an AI-supported application could help employees respond safely and efficiently.

View FactoryAssist AI Repository →
View Prototype Source →

Description

A manufacturing reaction-plan assistant with equipment selection, structured reaction plans, safety and escalation guidance, sample maintenance history, and a manager reliability dashboard.

Objective

Reduce confusion and response time during equipment issues by making approved reaction-plan information easier to locate and understand.

Process

  1. Identified operator, maintenance, and manager needs.
  2. Defined core features and user flow.
  3. Created a clickable front-end demonstration.
  4. Developed a FastAPI back end with sample reaction-plan matching.
  5. Added safety guidance, escalation steps, and sample equipment history.

Tools & Technology

HTML, CSS, JavaScript, Python, FastAPI, JSON, Git, GitHub, and AI-assisted development support.

Unique Value

Connects technical reaction-plan information with a simple interface designed around the immediate needs of manufacturing employees.

Relevance

Fast, consistent access to approved information could support safety, reduce downtime, preserve organizational knowledge, and improve communication.

References

FastAPI Documentation • Project materials and sample data are available in the linked repository.

Description

This project explores an AI assistant that could organize maintenance information and surface patterns that may indicate an emerging equipment problem.

Artifact 4System Design Concept

Plant Emergency Resource-Locator System

A plant emergency-response concept using numbered facility columns as a shared location framework for quickly locating hazards and emergency resources.

View Artifact Page →

Description

The proposed system would allow authorized users to locate fire extinguishers, electrical equipment, water supplies, piping, and other emergency resources near a reported column location.

Objective

Improve emergency communication and help facilities and safety teams find the correct resources quickly.

Process

  1. Identified the existing column-number system as the shared reference.
  2. Defined emergency-resource categories.
  3. Outlined a searchable location and resource database.
  4. Considered map, QR-code, mobile, and dashboard interfaces.
  5. Identified controlled-access and verification needs.

Tools & Technology

Process mapping, database planning, emergency-response workflow design, AI-assisted concept development, and planned dashboard/mapping technologies.

Unique Value

Builds on a location system employees already use, making the concept easier to understand and potentially faster to adopt.

Relevance

Accurate facility information can support faster emergency coordination while supplementing approved procedures, alarms, training, and professional responders.

References

OSHA Emergency Preparedness • OSHA 1910.38 Emergency Action Plans

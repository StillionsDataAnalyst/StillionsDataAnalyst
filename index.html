Screening Focus

Open Interactive ML Dashboard →
View Full Artifact →
View Python Code →

Model Comparison

Logistic Regression, Decision Tree and Random Forest were trained and evaluated on the same held-out test set.

Selected Model

Logistic Regression achieved 64.4% recall and 76.0% ROC-AUC, supporting a screening use case where missed elevated-risk cases matter.

Features

Downtime, cycle time, cycle-time variation, alarms, maintenance events, days since preventive maintenance, OEE and JPH attainment.

Tools

Python, Pandas, NumPy, scikit-learn, Logistic Regression, Decision Tree, Random Forest, Git and GitHub.
